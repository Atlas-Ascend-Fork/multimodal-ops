1. 融合方案

半融合双 kernel 结构

K1（Cube-only，PYPTO_fct_kernel_*）：
  HBM(input+weight) → L1(2-deep) → L0A/L0B → Cube 矩阵乘（隐式GEMM conv）→ L0C(fp32累加) → fixpipe → HBM(wsT)

K2（Vector-only，PYPTO_fct_tanh2nchw_*）：
  HBM(wsT) → UB → tanh 链（exp→neg→exp→sub→add→div，全程fp32）→ cast → HBM(output)

中间结果 wsT 经 HBM 一次往返，但 K1 和 K2 各自内部流水线满流水，互不等待。
选择半融合的依据：同类算子 fused_conv_sigmoid 实测半融合 4.56x 远优于真融合 2.87x——大 shape 时 per-tile Cube↔Vector 同步开销 > 省掉的 HBM 搬运。

cannbot 自测中解决的精度问题

  1. K 循环条件分支精度错误：maxdiff 3.6e-3 → 改为 host 侧堆叠消除条件分支 → maxdiff 降到 2.1e-7
  2. bias 折叠累加器量纲问题：bias 作为 3 个 K-block 加进累加器，|z|≈0 附近 tanh 精度超标 → 把 bias 从 K1 移到 K2 做逐行加法
